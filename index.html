Android Chrome: Android's Chrome permission and a website's microphone permission are separate. This page checks the microphone first, then releases the test microphone before starting speech recognition. It also prevents Chrome from appending the same recognition result more than once. For the most reliable speech recognition, open this tool from an HTTPS website. A downloaded .html file can have browser-origin limitations even when Chrome's Android microphone permission is enabled.
